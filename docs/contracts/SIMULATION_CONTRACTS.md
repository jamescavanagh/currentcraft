# Simulation contracts (generated)

Generated by `scripts/gen_contract_docs.py` from `src/app/application/simulation/contracts.py`.
Do not edit by hand: change the contract, then regenerate. CI fails when this file is stale.

Schema version: `datamesh-sim/v2`. Results are `embedding_geometry`: a procedural vortex field over embedded records,
not CFD and not an operational forecast.

Notation: lambda is inflow only. Jacobian eigenvalues are mu (`CriticalPoint.mu_min_abs`). Legacy `datamesh-sim/v1` payloads still read: the version is upgraded on input and the pre-0.9.8 key `lambda_min_abs` is accepted, but output is always the current version with `mu_min_abs`.

Layering: these models import Pydantic only. Arrays live in `app.infrastructure.tensors`; contracts carry `TensorRef`
handles (spec, key, concrete shape, SHA-256). Symbols such as `N`, `S`, `G` must bind to one size per contract instance.

## Feature orders

GNN node features (`GraphSample.x`, axis `feature`): `x`, `y`, `strength`, `abs_strength`, `sign`, `role_resource`, `role_process`, `role_operand`, `role_unassigned`, `speed`, `divergence`, `nearest_saddle_distance`, `basin_share`.
`nearest_saddle_distance` is -1 when no saddle exists at that inflow.

GNN edge features (`GraphSample.edge_attr`): `coupling`, `abs_coupling`, `distance`, `same_sign`. Edge j -> i carries k_ij (j's influence on i).

Field channels (`field`, `cnn.x`): `u`, `v`, `vorticity`, `divergence`, `speed`.

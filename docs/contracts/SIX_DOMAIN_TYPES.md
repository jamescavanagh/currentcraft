# Six concrete domain types (generated)

Generated by `scripts/gen_six_type_docs.py`; do not edit by hand.
Design: [Six concrete domain types](../domain/SIX_DOMAIN_TYPES.md).

Extensions hold exact canonical references; they never inherit canonical entities.
Shared extension fields are listed under `ExtensionRecord`; each model lists only its own fields.
Domain values are not public DTOs. Structural schema does not prove evidence truth or authority.
Use `--schema` for the combined JSON Schema. Schema SHA-256: `d2f7b02ed8adabca82d1ae67b79b3a5c89f1565d2d37f93236d4a43f5ea09a73`.

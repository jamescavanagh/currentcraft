### `ObjectIncidence`

| Field | Type | Required | Description |

| `effect` | `Literal['produces', 'consumes', 'reads', 'revises', 'holds', 'checks', 'transfers']` | yes | produces=birth, consumes=death, revises/transfers/holds=state change, checks=gate, reads=no change. |

| `state_after` | `Optional[str]` | no | State after the execution, where the effect changes state. |

### `PhaseChart`

Declared phase parameters. A research coordinate for similarity weighting, never the simulator plate phase.

    Bin weights for a phase at chart angle a: w_b proportional to exp(kappa * cos(phi_b - a)), phi_b = 2 pi b / bins,

| `origin_deg` | `float` | no (`0.0`) | Rotation applied to every anchor. |
| `direction` | `Literal['ccw', 'cw']` | no (`'ccw'`) | ccw adds angles, cw subtracts them. |
| `bins` | `int` | no (`12`) | Phase bins around the circle (B). |
| `concentration` | `float` | no (`4.0`) | von Mises kappa. 0 ignores phase entirely; large values separate phases. |
| `floor` | `float` | no (`0.05`) | Drop bins whose weight is below floor x the largest bin (sparsity). |

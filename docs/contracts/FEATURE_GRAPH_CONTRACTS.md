# Six-domain feature contracts (generated)

Generated by `scripts/gen_feature_graph_docs.py`; do not edit by hand.
Design: [six-domain evidence and versioned feature graph](../pipelines/OPERAND_COMPRESSION.md).

Run the generator with `--schema` for the combined JSON Schema. Structural schema
does not prove cross-record validity, evidence truth, physical compatibility or authority.

Schema SHA-256: `1d628ded48fe4ebb364764a0f0239e39c7af623d561aad952d3f51238f90dbb1`.

## `OperandRef`

Opaque reference to an existing thing at an exact record revision.

| Field | Required | Description |
| --- | --- | --- |
| `object_id` | yes | Existing opaque thing ID; never a person, resource or party. |
| `object_kind` | yes | Thing kind matching the explicit domain context. |
| `domain_context` | yes | One of the six scoped contexts, not a universal ontology. |
| `record_version` | yes | Exact source entity record version; no identity regeneration. |

## `ConfigurationLink`

Sourced, context-specific assertion; never an automatic state transition.

| Field | Required | Description |
| --- | --- | --- |
| `configuration_id` | yes | Opaque identity of the selected/requested/evidenced configuration. |
| `graph_id` | yes | Exact feature-model graph identity. |
| `graph_revision` | yes | Exact feature-model graph revision. |
| `predicate` | yes | Context-specific assertion, not compatibility or release authority. |
| `evidence_ids` | yes | Opaque supporting evidence references resolved privately. |

## `OperandProfile`

Candidate view of one existing thing; geometry and source records stay separate.

| Field | Required | Description |
| --- | --- | --- |
| `profile_id` | yes | Opaque identity of this candidate profile. |
| `operand` | yes | Existing entity reference with exact version. |
| `projection_ref` | yes | Opaque caller-supplied versioned projection reference. |
| `configuration_link` | no | Optional sourced link; absence asserts no configuration fact. |
| `interpretation_status` | no | No accepted policy or operational authority. |

## `Provenance`

Opaque evidence envelope; actual locators belong in authorized private storage.

| Field | Required | Description |
| --- | --- | --- |
| `evidence_id` | yes | Opaque evidence assertion identity. |
| `source_snapshot_id` | yes | Exact opaque source snapshot/revision, not a raw locator. |
| `captured_at` | yes | When this evidence was captured, timezone-aware UTC. |
| `method` | yes | Assertion method; neither option proves truth or authority. |

## `FeatureDefinition`

Stable feature identity with an independently versioned definition.

| Field | Required | Description |
| --- | --- | --- |
| `feature_id` | yes | Stable opaque feature identity across definitions. |
| `version` | yes | Definition version, independent of graph revision. |
| `definition_digest` | yes | SHA-256 of the exact private or synthetic definition. |
| `status` | yes | Explicit sourced definition status; omission is not retirement. |
| `mandatory` | yes | Whether the active feature is required by this restricted model. |
| `provenance` | yes | Evidence for this exact definition and status. |

## `FeatureConstraint`

Pairwise relation scoped to the enclosing exact graph revision.

| Field | Required | Description |
| --- | --- | --- |
| `constraint_id` | yes | Opaque constraint identity within this graph revision. |
| `kind` | yes | Requires is directed; excludes forbids joint selection. |
| `left` | yes | Antecedent or first excluded feature, resolved at this graph revision. |
| `right` | yes | Required or second excluded feature, resolved at this graph revision. |
| `provenance` | yes | Evidence for the relation, not mere co-presence. |

| Field | Required | Description |

## `AsOfRequest`

| Field | Required | Description |
| --- | --- | --- |
| `graph_id` | yes | Graph to reconstruct. |
| `effective_at` | yes | Effective-time cutoff, timezone-aware. |
| `known_at` | yes | Knowledge/recorded-time cutoff, explicitly supplied. |

## `FeatureGraphDiff`

Identity-level comparison, not causal inference or feature transfer evidence.

| Field | Required | Description |
| --- | --- | --- |
| `graph_id` | yes | Shared graph identity. |
| `before_revision` | yes | Earlier graph revision. |
| `after_revision` | yes | Later graph revision. |
| `before_digest` | yes | Exact earlier snapshot digest. |
| `after_digest` | yes | Exact later snapshot digest. |
| `introduced` | yes | Newly listed features, not proof of first historical invention. |
| `carried` | yes | Identical definition carried into the later snapshot. |
| `changed` | yes | Changed retained definitions, excluding explicit retirement. |
| `retired` | yes | Previously active definitions explicitly retired. |
| `no_longer_listed` | yes | Missing IDs, not evidence of retirement or absence. |
